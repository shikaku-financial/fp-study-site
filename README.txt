FP学科トレーニング 初期版

構成: index.html / questions.js / app.js
ブラウザでindex.htmlを開くと動作します。ビルド、アカウント、APIキー不要。
公開方法: GitHubリポジトリに3ファイルをアップロードし、GitHub Pagesを有効化するか、Cloudflare Pagesへデプロイしてください。
注意: 初期版は各級6問ずつの独自例題であり、本番形式の60問模試ではありません。公式試験の出題形式を参考にしていますが、公式サイトではありません。
問題の追加はquestions.jsのQUESTIONS配列に、重複しないidで追記してください。
ブラウザ内localStorageに正誤履歴を保存します。広告・分析タグは未実装です。
