# FPラボの回帰試験

リポジトリのルートで `node .ci/run.cjs` を実行する。Node.js 24、外部npm依存なし。
PR作成・更新時と手動実行時にGitHub Actionsが同じコマンドを実行する。
デプロイやmainへの書込みは行わない。

試験本数は `.ci/suites.json` で管理する。現在55本の試験、JavaScript 5ファイルの構文、学科360問・実技240問のIDと順序を確認する。
試験は一時ディレクトリで実行し、実データの保存先は使わない。35件の旧版資料・問題群を
fixturesに含め、採点・保存/再開・旧履歴・保存失敗・破損データ・古いタブ・開始失敗を検査する。
fixtures内の古い文言や仕様は過去スナップショットの再現用で、現在の推奨内容ではない。

各testの末尾のv番号は期待値の継承経路を表す。元の試験は完成版アーカイブに保持し、
ここには現行の実行対象だけを置く。固定した600IDのcontract.jsonはID変更を検出する契約であり、
問題改訂時に自動で作り直して検出を回避してはならない。

VM/DOMによる模擬試験で、実ブラウザ/iPhone・正式配点・法令の正しさ・全問包括監修を
証明するものではない。問題の条件や誤答根拠は別に点検する。

未公開保険差分：従来34 fixtureを維持し、旧5問を1ファイル追加。現行013は9万円、旧snapshotは10万円をそれぞれ検査。固定600ID契約は不変。
