# FP学科トレーニング v2

**無料・登録不要、ビルド不要。** HTML/CSS/JavaScriptだけでGitHub Pagesに公開できます。

## 収録機能
- FP3級：正誤式4問、三答択一式2問／FP2級：四答択一式6問
- 分野別演習、シャッフル、解答直後の解説、誤答復習
- 各級6問ミニ模試（10分）、前後移動・回答変更、制限時間で自動採点
- ミニ模試の途中保存と再開、受験履歴、分野別正答数、全問の解説表示
- 本番形式60問模試の出題エンジン（必要な有効問題数が揃うまでは開始不可）
- v1の学習履歴 `fp-training-v1` は維持

## 公開方法
`index.html`、`style.css`、`questions.js`、`app.js` を、同じリポジトリのルートにアップロードしてください。既存ファイルと同名なら上書きしてコミットします。`README.md` は任意です。ZIPファイルをそのままアップロードしてもサイトは動きません。

既存のGitHub Pages設定（main / root）を変更する必要はありません。

## 重要な制約
- 現在は各級6問の初期版です。**60問模試は未公開**です。3級には正誤30問＋三答択一30問、2級には四答択一60問が必要です。データ数・形式に加え、`verified: true` のある問題だけで構成します。検証フラグを付けても、法令・正答の内容検証を機械的に保証するものではありません。
- 現在の例題は法令基準日の検証を完了した問題バンクではありません。法令に依存する出題を増やす場合は一次資料で確認してください。
- 模試の途中経過は端末内に保持します。保存データの削除、ブラウザのデータ消去、端末変更では引き継がれません。
- 3級の60問模試では正誤30問→三答択一30問の順に並べます。2級は四答択一60問です。出題分野の本番どおりの配分は別途精査が必要です。
- GitHub Pagesの公開リポジトリには機密情報や個人情報を入れないでください。
