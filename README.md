# FP学科トレーニング Ver.6

無料・会員登録不要のFP2級／3級学科試験向け学習サイト。GitHub Pagesで公開可能な純粋なHTML/CSS/JavaScriptで動きます。

## Ver.6の改善点

1. 60問模試で各問題を「☆ この問題を見直す」に指定できます。★の問題へジャンプできます。途中保存・再開でも見直し指定が残ります。
2. 模試終了後の答え合わせをブラウザに保存できるようになりました。ホームの「学習記録」から「答え合わせを開く」を選択すると、後から誤答・未回答、すべての問題、解説を表示できます。
3. 模試を受けた時点の問題文・選択肢・正答・解説を保存するため、将来のコンテンツ更新でも過去の解答内容を取り違えにくい構造です。
4. FP3級60問（○×30、三択30）とFP2級60問（四択60）の問題内容はVer.5から変更していません。旧データも引き継ぎます。

## iPhoneで既存GitHub Pagesサイトを更新する方法

1. Ver.6のZIPをiPhoneの「ファイル」で解凍します。
2. https://github.com/shikaku-financial/fp-study-site/upload/main をSafariで開きます。
3. **ZIPをアップロードするのではなく**、解凍したフォルダの `index.html`, `style.css`, `questions.js`, `app.js` の4ファイルを選択します。必要なら `README.md` も更新してください。
4. 緑色の `Commit changes` で保存します。数分後に https://shikaku-financial.github.io/fp-study-site/ を更新して動作を確認します。

## 監査上の注意

問題の形式・データ構造と操作の自動テストは実施済みですが、120問すべての法令・税制・実試験難易度は監修未完了です。重複設問や今後の改善点は `QA_REPORT.md` を参照してください。個人情報の登録は求めず、回答履歴は使用中のブラウザ内に保存されます。
