# FP学科・実技トレーニング Ver.11

iPhoneからGitHub Pagesに設置できる、無料・登録不要の静的サイトです。

## Ver.11の主な変更点

1. **サイト名「FP学科・実技トレーニング」をタップでトップに戻れます。** 学科模試・実技演習の途中から戻る場合は、それぞれの途中回答をブラウザ内に保存します。
2. **「ご利用にあたって」を短く表示**するよう変更しました。通常は重要事項の要約だけを示し、「詳しい注意事項を表示」をタップすると詳細が開きます。再度タップして閉じられます。
3. **金財2級の実技4科目を追加**しました。個人資産相談業務・中小事業主資産相談業務・生保顧客資産相談業務・損保顧客資産相談業務について各5事例×3問、合計60問のオリジナル体験演習を収録しました。
4. 実技演習を中断した後に再度科目選択を開く際の表示処理を修正しました。

既存の学科360問（FP2級180問、FP3級180問）は全件維持。実技は従来の54問に60問を追加し、**計114問・8科目**となっています。実技演習で使うlocalStorageキーはVer.10と共通です。

## iPhoneでのアップロード

1. このZIPをiPhoneの「ファイル」アプリで解凍します。
2. Safariで https://github.com/shikaku-financial/fp-study-site/upload/main を開きます。
3. 解凍したフォルダ内の下記**6ファイル**を選択し、リポジトリの最上位階層（root）へアップロードします。
4. 緑色の「Commit changes」を押します。既存の同名ファイルは上書き更新されます。
5. 数分待ち、 https://shikaku-financial.github.io/fp-study-site/ を再読み込みします。トップに「Ver.11」と表示されれば更新完了です。

### アップロードするファイル

- `index.html`
- `style.css`
- `questions.js`
- `app.js`
- `practical-questions.js`
- `practical.js`

ZIP自体や画像ファイル、README、QA_REPORTはアップロード不要です。

## 重要事項

このサイトは試験実施団体の公式サービスではありません。掲載問題は公表過去問を参考に**独自作成**した練習問題で、実技は正式な配点・合格判定に対応していません。学科・実技問題の全問について専門家監修・最新法令確認が完了したわけではありません。参考の金財2026年5月公表PDFは、原則2025年4月1日現在の法令を基準としています。

変更前に既存の演習を完了しておく必要はありませんが、機種変更・ブラウザの履歴消去などでlocalStorageが消える場合があります。GitHubへのファイルアップロードは、通常この端末の学習履歴を消去しません。
