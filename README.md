# FP学科トレーニング Ver.3｜各級30問

iPhone・GitHub Pages向け、無料・登録不要の静的サイトです。React・Node.js・ビルド工程は不要です。

## 今回の変更
- **既存12問は変更・削除しません**。新たにFP3級24問とFP2級24問、合計48問を追加。
- **FP3級：30問（正誤式15問＋三答択一式15問）**。6分野それぞれ5問。
- **FP2級：30問（四答択一式30問）**。6分野それぞれ5問。
- 6問ミニ模試は**6分野から各1問**を抽出するよう改善しました。
- 端末の学習記録は旧版と同じ `fp-training-v1` を使用し、既存履歴を維持します。
- 本番形式60問模試は検証済みの問題が不足しているため**引き続き使用不可**です。

## 更新方法
GitHubの `shikaku-financial/fp-study-site` リポジトリで、ZIPを解凍した中の `index.html` `style.css` `questions.js` `app.js` をリポジトリ直下にアップロードしてください。`README.md` の更新は任意です。GitHub Pagesの設定変更は不要です。

## ご注意
設問は過去問を複製したものではなく、オリジナルの基本問題です。税制・相続等を含む学習用問題であり、**日本FP協会の公式問題・監修済み問題ではありません**。2026年10月時点で金額改正などの年度依存問題をできる限り避けていますが、全問題の法的・実務的な監修は完了していません。

設問の形式・回答インデックス・選択肢数の自動テストは実施していますが、記述内容に対する人間の専門家監修の代わりにはなりません。
