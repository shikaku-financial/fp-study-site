# FP学科トレーニング Ver.8（各級120問）

iPhoneだけで更新できる静的Webサイトです。HTML / CSS / JavaScript を使用し、Node.js、Bolt、有料サービスは不要です。

## 変更点

- FP3級：60問 → **120問**（正誤式60問・三答択一式60問）
- FP2級：60問 → **120問**（四答択一式120問）
- 両級とも全6分野に各20問を配置。
- **60問模試**は、3級では各分野の正誤式5問と三択5問、2級では各分野から四択10問をランダム選出。試験時間は3級90分、2級120分。
- 分野別の問題演習で10・20・30・60問・全問を選択可能（問題数が足りない分野の場合は、その分野の収録問題まで出題）。
- Ver.7の120問、ID、revision、学習履歴、途中保存模試、過去の答え合わせの保存形式を維持。

## iPhone・GitHub Pagesでの更新

1. `fp-study-site-v8.zip` をダウンロードしてiPhoneの「ファイル」アプリで解凍。
2. https://github.com/shikaku-financial/fp-study-site/upload/main をSafariで開く。
3. 解凍フォルダから **`index.html`、`style.css`、`questions.js`、`app.js`** の4ファイルを選んでアップロード。
4. 「Commit changes」を押す。GitHub Pages設定は変更不要。
5. https://shikaku-financial.github.io/fp-study-site/ を再読み込み。画面に **「Ver.8｜各級120問」** と表示されれば反映済み。

`README.md`、`QA_REPORT.md` は説明文書です。サイトを動かすためのアップロードは不要です。`new-questions.json` も作業用差分なのでアップロード不要です。

## 注意

- 問題は独自に作成した学習用例題です。実際の試験問題や難易度を再現・保証するものではありません。
- **新規120問の全問について、法令根拠を独立に確認したわけではありません。** 追加問題の `verificationStatus` は `needs_review` とし、法令基準日を未確認のまま設定していません。
- 計算例とデータ構造の検査、ブラウザ動作テストは実施していますが、専門家監修ではありません。
- 学習履歴は利用中のブラウザ内に保存されます。ブラウザデータの削除や端末変更では引き継げません。
- 一部の問題に内容の類似があります。今後、難易度と出題テーマの網羅性を改善する予定です。
