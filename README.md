## iPhoneでGitHub Pagesを更新

1. ZIPファイルをiPhoneの「ファイル」アプリで解凍。
2. https://github.com/shikaku-financial/fp-study-site/upload/main をSafariで開く。
3. フォルダ直下の **index.html / style.css / questions.js / app.js の4ファイル** をまとめて選択。
4. 「Commit changes」をタップ。
5. https://shikaku-financial.github.io/fp-study-site/ を更新。画面に「Ver.7」が表示されているか確認。

GitHub Pagesの設定変更や有料プランの契約は不要です。

**注意：** ZIPだけをGitHubにアップロードしてもサイトは更新されません。旧版の4ファイルと同じリポジトリのルートにアップロードしてください。
