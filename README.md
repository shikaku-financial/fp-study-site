# FP学科・実技トレーニング Ver.12

学科FP2級180問・3級180問、実技114問、合計474問のオリジナル学習サイト。

## Ver.12の変更
- 誤答選択肢が極端で正解が簡単に分かる設問を重点的に改訂。
- 計算の典型的な誤り、近い制度の混同、適用条件の違いを使って選択肢を作成。
- 問題によって誤答理由も解説に追記。
- 正答が選択肢の前半に偏っていたため、選択肢と正答インデックスを再配置して正答位置の偏りを改善。
- 全問題の専門家監修・最新法令確認が済んでいるわけではありません。
- 正式リリース前につき、過去の学習履歴の移行・補正は追加していません。残る履歴の判定が改訂問題と一致しない場合は、サイトの学習記録削除機能で初期化できます。

## iPhoneから更新する
1. ZIPをiPhoneの「ファイル」で解凍。
2. https://github.com/shikaku-financial/fp-study-site/upload/main をSafariで開く。
3. 解凍したフォルダの `index.html`、`style.css`、`questions.js`、`app.js`、`practical-questions.js`、`practical.js` を選択。
4. `Commit changes` を押す。
5. https://shikaku-financial.github.io/fp-study-site/ で Ver.12 表示を確認。

サイトは非公式の学習用です。過去問の転載はしていません。
