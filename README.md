# FP学科トレーニング Ver.4｜各級60問・模擬試験対応

追加料金やビルド不要で動作する、HTML・CSS・JavaScript製のFP2級・FP3級学科試験対策サイトです。GitHub Pagesで公開できます。会員登録や個人情報入力は不要です。

## 収録内容

| 級 | 問題数 | 内訳 | 60問模試の制限時間 | 学習用の合格圏判定 |
|---|---:|---|---:|---:|
| 3級 | 60 | ○×式30問＋三答択一式30問 | 90分 | 36問以上正解 |
| 2級 | 60 | 四答択一式60問 | 120分 | 36問以上正解 |

それぞれ6分野×10問。以前のVer.3の各級30問（合計60問）は、問題ID・内容・正答ともに**変更せず残しています**。各級30問を新規追加し、合計120問となりました。

## 主な機能

- 級別・分野別の問題演習、出題順シャッフル
- 間違えた問題の復習
- 6分野から1問ずつ出題する6問ミニ模試（10分、合否判定なし）
- 本番の時間・出題形式に合わせたオリジナル60問模試
- 問題ごとの回答変更、未回答のままスキップ、問題番号から移動
- 途中保存・再開（制限時間は一時停止しません）
- 時間切れ時の自動採点、36点基準の学習用判定、分野別成績、全問の解説
- 模試履歴、端末内の回答履歴を保存

## iPhoneから既存のGitHub Pagesを更新する方法

1. `fp-study-site-v4.zip` をダウンロードして「ファイル」アプリで解凍します。
2. https://github.com/shikaku-financial/fp-study-site/upload/main をSafariで開きます。
3. このフォルダ内の `index.html`、`style.css`、`questions.js`、`app.js` を**リポジトリ直下**へアップロードします。`README.md` の追加・更新も可能です。
4. `Commit changes` をタップします。既存のGitHub Pages設定は変更不要です。
5. 数分後に https://shikaku-financial.github.io/fp-study-site/ を開いて、級の切替と「60問模試を開始する」ボタンを確認してください。

**注意：** このZIPの `index.html` と3つのJS/CSSファイルは同じ階層へ置いてください。ZIPファイルそのものをGitHubにアップロードしないでください。

## 学習履歴の互換性

Ver.2・Ver.3と同じlocalStorageキー `fp-training-v1`、`fp-training-exam-history-v2`、`fp-training-exam-draft-v2` を利用しています。既存問題のIDは変更せず、通常のGitHub更新だけで学習履歴は消去されません。ただし、別のブラウザや端末、プライベートブラウズ、サイトデータ消去などでは履歴を引き継げない場合があります。

## ご利用上の重要な注意

- 本サイトは学習用の**非公式サイト**であり、日本FP協会の提供・監修・保証を受けたものではありません。
- **問題の正答・解説について、専門家による全問監修は未実施です。** 問題文や解説、制度の解釈に誤りが残る可能性があります。法改正にも注意が必要です。
- 60問模試は、問題数・形式・時間・採点基準を公式情報に合わせた**オリジナル例題による模擬試験**です。難易度・出題傾向・合否予測の精度について本試験と同等であることを保証しません。
- 2024～2026年に公表された参考問題の**文章は転載していません**。
- 試験時間・問題数・合格基準の確認先：日本FP協会 https://www.jafp.or.jp/exam/outline/
- 過去に保存した途中模試の解答は、旧版の問題IDがそのまま残るため原則として再開可能です。途中模試を新規模試で上書きする場合には確認ダイアログが表示されます。
