# FPラボ Ver.17

Ver.16をベースにした実技演習の復習機能改善版。学科360問、実技240問を維持。

- 実技の採点後「間違えた問題だけ再演習」を追加（未回答も対象）。全問正解なら無効化。
- 「同じ科目に再挑戦」は直前に受けた同一問題セットを再出題。金財第2回を第1回と取り違えない。
- 再演習中も途中保存・再開・採点・履歴保存を利用可能。
- 教材の専門家監修・2026年法令の全問照合は未完了。
