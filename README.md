# FP学科・実技トレーニング Ver.13

## 更新内容

- 実技科目の選択画面を「FP3級 / FP2級」タブで分離。
- 各級の科目を「日本FP協会」と「金融財政事情研究会（金財）」のグループごとに整理。
- 実技演習の採点済み履歴を1件ずつ削除可能。全件削除も可能（操作前に確認あり）。
- 受験履歴の削除は**実技履歴だけ**に作用します。学科の学習記録・模試履歴・実技の途中保存は残ります。
- 問題数は変更せず、学科360問、実技114問を維持。

## iPhoneで更新する方法

ZIPを解凍して `index.html`, `style.css`, `questions.js`, `app.js`, `practical-questions.js`, `practical.js` の6ファイルをGitHubリポジトリ直下にアップロードします。同じファイル名で上書きし、`Commit changes` を押してください。GitHub Pagesの設定変更は不要です。

Ver.12の保存キーを引き続き使い、不要なデータ削除はしません。受験履歴は現在の仕様上直近8件まで保存されます。

全問の法令・専門監修は未完了です。公開前に確認してください。
