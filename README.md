# FP学科トレーニング Ver.5

iPhone・Safariで利用できるFP2級/3級の無料・登録不要の静的学習サイトです。GitHub Pagesを含む静的ホスティングで利用できます。

## Ver.5での改善

- 60問模試の問題番号一覧を**開閉式**に変更。初期状態は閉じ、必要なときだけ60問の番号を表示します。
- **次の未回答へ移動**ボタンを追加。現在位置より後の未回答、なければ先頭から探して移動します。
- 採点結果を**「要復習」と「全問表示」**で切り替え可能にしました。誤答・未回答を優先表示し、1問ずつタップすると解説が開きます。
- 解答記録と模試途中経過の保存キー・構造はVer.4と同じです。
- 既存120問の本文・選択肢・解答・解説および問題IDは**変更していません**。

## iPhoneからGitHubに反映する方法

1. Ver.5 ZIPを「ファイル」アプリで展開。
2. Safariで https://github.com/shikaku-financial/fp-study-site/upload/main を開く。
3. **index.html / style.css / questions.js / app.js** の4ファイルを選択します。必要ならREADME.mdも上書きしてください。
4. 「Commit directly to the main branch」を選び、「Commit changes」で保存。
5. 数分後に https://shikaku-financial.github.io/fp-study-site/ をSafariで確認します。更新が見えなければ再読み込みしてください。

`QA_REPORT.md`とスクリーンショットはサイトの動作に不要です。

## 注意

- 模試の制限時間：FP3級90分・FP2級120分。各60問、学習用の合格圏表示は36問正解以上。
- 法改正への追従・正答や解説の専門家監修は**未完了**です。公式の試験情報や法律・税制の確認に代わるものではありません。
- 現在は同一テーマの設問が複数含まれています。`QA_REPORT.md`を参照してください。
- データはブラウザのlocalStorageに保存され、端末やブラウザを変えると引き継がれません。Safariの履歴・サイトデータ削除でも失われる場合があります。
- 広告、個人アカウント、サーバーへの学習履歴送信は実装していません。
