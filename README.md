# FP学科対策ラボ（初期版）

FP2級・3級向けの無料・登録不要の静的学習サイトです。HTML/CSS/JavaScriptのみで動き、ビルドや有料サービスは不要です。

## 収録内容
- FP3級：正誤式4問、三答択一式2問
- FP2級：四答択一式6問
- 6分野選択、正誤判定、解説、誤答復習、級別学習履歴
- 回答直後にlocalStorageへ保存

## 利用方法
`index.html` をブラウザで開くか、GitHub Pages / Cloudflare Pagesで公開してください。公開時はファイル4つ（index.html, style.css, questions.js, app.js）を同じディレクトリに配置します。

## GitHub Pagesでの公開（iPhone Safari）
1. GitHubの無料アカウントを作成し、公開リポジトリを新規作成。
2. このZIPをiPhoneの「ファイル」アプリで展開し、各ファイルをリポジトリのルートにアップロード。
3. GitHubのリポジトリ「Settings」→「Pages」で「Deploy from a branch」→「main / (root)」を選択し保存。
4. 公開URLが表示されるまで待つ。GitHubの画面表記は変更される場合があります。

## 重要
本サイトは初期版であり、本番形式の60問模試は未実装です。問題はオリジナルの基本概念の例題です。法令基準日・出典の個別検証を経た問題バンクではありません。法令依存の新規問題を公開する前に、一次資料による確認が必要です。GitHub Pagesでの公開リポジトリはコードと問題が一般公開されます。個人情報や秘密鍵を登録しないでください。
