## iPhoneでの更新

1. ZIPをダウンロードし「ファイル」アプリで解凍する。
2. Safariで https://github.com/shikaku-financial/fp-study-site/upload/main を開く。
3. 解凍したフォルダ内の**以下の6ファイル**を選択する。ZIPそのものはアップロードしない。
   - `index.html`
   - `style.css`
   - `app.js`
   - `questions.js`
   - `practical-questions.js`（新規）
   - `practical.js`（新規）
4. `Commit changes` をタップする。GitHub Pages の設定変更は不要。
5. https://shikaku-financial.github.io/fp-study-site/ を開き、「Ver.10」「実技試験の科目を選ぶ」を確認する。

**重要：今回から新しいファイルが2つ増えているため、従来の4ファイルだけでは実技モードは動作しません。必ず6ファイルをアップロードしてください。**
