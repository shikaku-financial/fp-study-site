# FPラボ Ver.18

ファイナンシャルライセンスラボ内のFP2級・3級学科／実技演習サイト。

## 変更点

- 学科演習の「1回の演習問題数」は、級・出題分野に応じて利用可能な件数のみ表示。全分野の場合は10・20・30・60問／全180問、個別分野では10・20・30問／全30問（現行データの場合）。
- 分野変更時に現在の指定が上限を超えると、自動的に実行可能な件数へ調整。「すべて」は選択分野の全問題を意味する。
- FP2級の計算・数量問題15問の不正解選択肢を、実際に起こり得る計算の取り違えに近い数値へ改訂。解説に誤答の理由を追記。
- 学科360問・実技240問を維持。ロゴ、実技科目、採点・復習・保存機能も維持。
