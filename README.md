# FP学科・実技トレーニング Ver.14

## 変更内容

- ロゴや認証風マークは使用せず、試験実施団体への外部リンクをトップページに新設。
- 日本FP協会：試験要綱、公表問題・模範解答へのリンク。
- 金財：試験情報、公表問題・模範解答、法令基準日へのリンク。
- 公式資料の参照と問題の専門家監修は異なることを明記。
- 学科の解答後の解説・模試の答え合わせに「参考情報・確認状況」欄を追加。
- 実技の答え合わせにも参考資料と法令基準日の注記を追加。
- 「ご利用にあたって」は短縮表示を維持し、運営方針・免責・プライバシー・広告・窓口準備状況を開閉式で追加。
- 原則2025年4月1日基準の2026年5月公表問題と、現行の金財CBT試験（2026年6月〜2027年5月）の2026年4月1日法令基準日の違いを案内。

## 更新方法

ZIPを解凍し、`index.html`、`style.css`、`questions.js`、`app.js`、`practical-questions.js`、`practical.js` の6ファイルをGitHubリポジトリ直下にアップロードして、Commit changes を実行してください。GitHub Pagesの設定変更は不要です。

## 正式公開前の確認事項

1. 日本FP協会のウェブサイト利用条件に従い、リンク元URLを同協会に連絡してください（ `info@jafp.or.jp` ）。
2. 運営者の連絡窓口を確保してください。本版ではお問い合わせ窓口を「準備中」と明記しています。
3. 個人情報の取扱い、広告やアクセス解析を設置する場合の必要な告知・同意、広告事業者の規約を再確認してください。
4. 問題の専門家監修・現行法令との照合は未完了です。リンク先があるだけで正確性を保証することはできません。
5. 本バージョンは情報表示・UIの改良版です。学科360問・実技114問の問題内容・採点方法は変更していません。
